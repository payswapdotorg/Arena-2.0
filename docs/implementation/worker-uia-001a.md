## What was built

1. **Design system (`src/design/`)** — the complete `--arena-*` token set (`arena-tokens.css`, 38 tokens across 10 frozen groups: brand/surface/text/border/status/evidence/focus/spacing/radius/motion), layered on inherited host-theme surfaces with light-theme calibration, reduced-motion support, and a TS mirror catalog (`tokens.ts`) that tests assert against the CSS (bidirectional coverage — no orphan CSS tokens, no dead mirror entries). Status and evidence-grade tokens map 1:1 to the typed vocabularies (pass/denied/blocked/pending; DEMO/FIXTURE/REAL).
2. **Identity kit (`src/identity/`)** — `ArenaWordmark` (inline SVG, three-tier A glyph + ARENA wordmark, `data-arena-wordmark`, a11y labels, monochrome mode); `statePatterns.tsx` (Welcome/Empty/Loading/Error + `ArenaPostureBar` — honest copy, typed errors verbatim, retry only when wired, posture constants verbatim); `productTitle.ts` (document-title ownership: `Arena — <screen>`, restore-on-unmount, full frozen-vocabulary coverage).
3. **Navigation (`src/nav/model.ts`)** — pure logic layer: roving-tabindex key order (next/prev wrap, Home/End endpoints), the single refusal-text source (verbatim, never softened), and `#/<screenId>` deep-link hash round-trip (unknown hashes → null — the shell never guesses).
4. **The shell (`src/shell/`)** — `ArenaShell` reworked from the Wave 0 stub into the real product shell: brand position (wordmark), vertical nav rail over the frozen five-screen vocabulary (ARIA tablist/tab semantics, `aria-current`, per-item "not registered" honesty), roving-tabindex keyboard navigation (arrows/Home/End; move = navigate), skip-link into the main landmark, typed-refusal notice surface (`role="alert"`), posture footer (`ArenaPostureBar`), role-lens switcher (presentation-only vocabulary, disclosed in its aria-label, no authority language), solution-workspace slot passed through (null during lanes). `shell.css` implements the inherited focus law (rings drawn on wrapper layers via `:has()` because the upstream global `*:focus` reset kills direct outlines) and the responsive law (>=960px rail; <960px compact top bar; 390x844 no horizontal overflow; i18n-length-tolerant labels). `registry.ts` unchanged from Wave 0 (frozen behavior).
5. **Branding sweep (the enumerated files only)** — locale catalogs `packages/ui/src/i18n/locales/en-US.ts` (101 value-side replacements) and `zh-CN.ts` (97): every user-visible "ZCode" product-name mention becomes "Arena" (keys untouched — internal identifiers; `x-zcode-bot-secret`, `.zcode/v2`, `.zcodeignore`, and the single `toggleZCodeStdioTap` key preserved verbatim); `WindowsTopLeftLogo.tsx` becomes the inline Arena wordmark (geometry/layout preserved, no new asset file); `packages/web/index.html` title becomes Arena (title only); `packages/desktop/package.json` `productName` becomes Arena (that field only). LICENSE/NOTICE/THIRD-PARTY-NOTICES untouched (attribution preserved verbatim).
